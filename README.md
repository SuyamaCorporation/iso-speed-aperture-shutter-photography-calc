## ISO/Aperture/Shutter Speed Exposure Triangle Calculator

Interactive exposure triangle tool with three linked sliders for ISO (100-12800), Aperture (f/1.4-f/22), and Shutter Speed (1/8000s-30s). Displays Exposure Value (EV), a visual light meter bar, depth-of-field description, and a list of equivalent exposures when two parameters are locked.

**Tech:** Vanilla JS, Tailwind CSS CDN, logarithmic EV calculations.

**How to use:** Adjust sliders to set exposure values. Check the lock boxes on any two parameters, then the equivalent exposures panel shows valid combinations for the free parameter at the same EV.
